# GrowthOS CRM

GrowthOS CRM is a complete E-commerce and Lead Management System designed for businesses running Meta Ads, WhatsApp Sales, and Online Stores.

## Features

### Lead CRM
- Lead Capture
- Lead Assignment
- Lead Status Tracking
- Counselor Tracking

### E-commerce Analytics
- Revenue Tracking
- Delivered Orders
- Cancelled Orders
- Net ROAS

### Marketing Attribution
- Campaign Name
- Ad Set Name
- Ad Name
- UTM Tracking

### Automation
- WhatsApp Follow-up
- Abandoned Cart Recovery
- Conversion Tracking

### Integrations
- Meta Conversion API
- Shopify API
- Google Sheets
- Looker Studio

## Tech Stack

- Python
- Google Apps Script
- Google Sheets
- Meta API
- Shopify API
- Looker Studio
